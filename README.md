# Ad-AIGC-6s — Pipeline, Training, and Artifacts

[![DOI](https://zenodo.org/badge/1158846191.svg)](https://doi.org/10.5281/zenodo.18653639)

This repository provides an end-to-end pipeline for:
- constructing a real→AI short-form ad dataset (optional; requires lawful local access to videos),
- computing quality/similarity signals,
- constructing the retained-persuasion proxy target,
- training/evaluating three fusion architectures,
- regenerating tables/figures/statistical tests from released artifacts.

## What’s included (and what isn’t)

- **Included**: `src/`, `scripts/`, `main.py`, `config.yaml`, `requirements.txt`, and released non-video artifacts under `data/metadata/` and `experiments/`.
- **Included (derived artifacts)**: `experiments/` contains prediction CSVs, checkpoints, and logs used by the table/figure generation scripts; it is intentionally included to enable artifact-only reproduction.
- **Not included**: real advertisement videos and AI-generated videos. The repository supports **artifact-only reproduction**, allowing regeneration of tables, figures, and statistical tests directly from released CSV artifacts without accessing any video files.

All tables, figures, robustness tests, and sensitivity analyses can be reproduced without accessing or generating any video content.

## Repository structure

- `config.yaml`: model/data/training defaults (used by `main.py`)
- `main.py`: training + evaluation entrypoint (writes `test_predictions.csv`, checkpoints, logs)
- `src/`: core library
  - `src/models/`: fusion architectures and quality-gated attention
  - `src/data/`: dataset loading / feature assembly
  - `src/training/`: training loop, early stopping, evaluation
  - `src/utils/`: reproducibility helpers
- `scripts/`: pipeline scripts (artifact regeneration, optional video pipeline, analysis)
- `data/metadata/`: released CSV artifacts (datasets, quality metrics, generation logs, lambda datasets)
- `experiments/`: released predictions/checkpoints and analysis outputs
- `paper_artifacts_out/`: regenerated tables (CSV / LaTeX)
- `outputs/paper_artifacts/`: generated figures
- `supplementary/`: supporting artifacts (e.g., K-frame sensitivity CSVs, multi-seed tables)

## Core definitions (proxy construction)

### \(P_{real}\) scaling

Source effectiveness labels are scaled to \([0,1]\) as:

\[
P_{real}=\frac{\texttt{effective\_score}-1}{4.0}.
\]

### Main benchmark filtering

The main benchmark filters to source ads with \(P_{real}\ge 0.5\) (equivalently \(\texttt{effective\_score}\ge 3\)).

### Proxy target \(P_{retained}\)

\[
P_{retained}=P_{real}\cdot(\lambda q_{ai}+(1-\lambda)S_{sim}),
\]

where:
- \(q_{ai}\in[0,1]\): aggregate quality proxy (0.6× mean VBench-inspired + 0.4× mean EvalCrafter-inspired dimensions),
- \(S_{sim}\in[0,1]\): CLIP-based semantic similarity between real and AI videos.

## Common workflows

### A) Artifact-only regeneration (no videos)

This workflow reproduces all quantitative results reported in the paper, including main tables, robustness statistics, sensitivity analyses, and significance tests.

Regenerates tables/figures from the released `data/metadata/` + `experiments/` artifacts:

```bash
python scripts/run_full_pipeline.py --run_artifacts
```

Outputs:
- `paper_artifacts_out/` (tables as CSV / LaTeX)
- `outputs/paper_artifacts/` (figures)

| Element | Source in repository |

### B) Train one fusion model from a released dataset CSV (no videos)

You can switch the fusion architecture in either of two ways:

- **Option 1 (edit config)**: change `model_ad_aigc_6s.fusion.type` in `config.yaml` to one of:
  - `concat`
  - `standard_attn`
  - `quality_gated`
- **Option 2 (CLI override, recommended)**: pass `--fusion_type ...` to `main.py` (no config edits).

Examples (single-seed runs):

```bash
python main.py --config config.yaml \
  --dataset_csv data/metadata/ad_aigc_6s_main_experiment_cached.csv \
  --fusion_type concat \
  --seed 42 \
  --output_dir experiments/concat_42
```

```bash
python main.py --config config.yaml \
  --dataset_csv data/metadata/ad_aigc_6s_main_experiment_cached.csv \
  --fusion_type standard_attn \
  --seed 42 \
  --output_dir experiments/standard_attn_42
```

```bash
python main.py --config config.yaml \
  --dataset_csv data/metadata/ad_aigc_6s_main_experiment_cached.csv \
  --fusion_type quality_gated \
  --seed 42 \
  --output_dir experiments/quality_gated_42
```

### C) Robustness checks (3 seeds × 3 fusions)

Runs training/evaluation for:
- fusions: `concat`, `standard_attn`, `quality_gated`
- seeds: `42`, `123`, `999`

```bash
python scripts/run_full_pipeline.py --run_robustness
```

Outputs:
- `experiments/robustness/{fusion}_{seed}/test_predictions.csv`
- `experiments/robustness/robustness_summary.csv`

### D) Sensitivity analysis (lambda sweep)

Trains/evaluates across a sweep of proxy-mixing coefficients \(\lambda\) using prebuilt datasets under `data/metadata/lambda_sensitivity/`:

```bash
python scripts/run_full_pipeline.py --run_sensitivity
```

Outputs:
- `experiments/lambda_sensitivity/lambda_sensitivity_per_run.csv`
- `experiments/lambda_sensitivity/lambda_sensitivity_summary.csv`

### E) Pilot / ablation (inference-step study)

Consumes `data/metadata/quality_metrics_pilot.csv` and generates a quality–compute trade-off plot:

```bash
python scripts/run_full_pipeline.py --run_pilot
```

This will run:
- `scripts/ablation_study_analysis.py` → `outputs/paper_artifacts/figure_3_ablation_elbow.png`

## Optional: end-to-end video pipeline (requires local videos + additional compute)

These steps are only needed if you want to regenerate videos and recompute signals from scratch. They require local access to the underlying videos and additional dependencies (e.g., `ffmpeg`; GPU recommended for SVD generation and CLIP similarity).

### Important clarification about video handling and compliance

- This repository **does not download videos** from YouTube or any other platform.
- All video-related steps assume **lawful, local access** to source videos obtained independently by the user.
- Automatic video downloading functionality has been **removed** for regulatory and copyright compliance.
- All reported results can be reproduced **without any video files** by running the artifact-only pipeline.

```bash
# operates on locally available videos only
python scripts/run_full_pipeline.py \
  --ensure_annotations \
  --run_download \
  --run_prompts \
  --run_generation_pilot \
  --run_generation_main \
  --recompute_quality \
  --recompute_similarity \
  --gen_device 0
```
Notes:
- `--run_download` assumes locally available raw videos in the expected directory layout.
- Use `--max_videos N` to cap processing for quick tests.

## What each script does (high-level)

### Orchestration
- `scripts/run_full_pipeline.py`: single entrypoint to run artifact regeneration, training, robustness, sensitivity, pilot analysis, and optional video-related steps.

### Tables / figures / statistics
- `scripts/generate_tables_and_figures.py`: builds tables from prediction CSVs + dataset CSV; also computes correlation tables for selected quality dimensions.
- `scripts/calc_significance.py`: paired bootstrap significance test given two `test_predictions.csv` files.
- `scripts/generate_gating_plot.py`: loads a trained quality-gated model and extracts gate activations to generate an interpretability plot.
- `scripts/build_missing_baselines.py`: creates deterministic baseline predictors on the fixed test split.

### Pilot / ablation analysis
- `scripts/ablation_study_analysis.py`: consumes `data/metadata/quality_metrics_pilot.csv` and generates the pilot trade-off plot.

### Robustness / sensitivity
- `scripts/run_robustness_check.py`: trains/evaluates 3 fusions × 3 seeds and writes `experiments/robustness/robustness_summary.csv`.
- `scripts/run_lambda_sensitivity.py`: trains/evaluates across lambda-sweep datasets and writes sensitivity summary CSVs.

### Optional: video pipeline
- `scripts/fix_annotations.py`: retrieves/extracts annotation JSONs into the expected directory layout.
- `scripts/extract_climax_segments.py`: creates 6-second center-window real clips (idempotent; skips existing outputs).
- `scripts/build_prompts.py`: builds `data/metadata/ad_prompts.csv` and applies the \(P_{real}\ge 0.5\) filter.
- `scripts/generate_svd_variants.py`: generates AI variants (pilot or main mode) and writes generation logs.
- `scripts/compute_quality_metrics.py`: computes OpenCV-derived quality metrics from videos.
- `scripts/compute_similarity_and_labels.py`: computes CLIP similarity and constructs labeled datasets (includes `--k_frames` for frame-sampling sensitivity runs).

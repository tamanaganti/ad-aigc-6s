# Supplementary Materials (inspection / verification; optional)

These materials are provided for **inspection and verification** and are **not required** to reproduce any tables or figures generated by the main pipeline. The primary workflows described in the top-level `README.md` do not require anything in `supplementary/`.

## What’s inside

### `k_frame_sensitivity/`

Artifacts supporting the choice **\(K=8\)** frames for stable CLIP similarity estimates with diminishing returns for larger \(K\).

- `sim_k4.csv`, `sim_k8.csv`, `sim_k12.csv`, `sim_k16.csv`: outputs from running `scripts/compute_similarity_and_labels.py` on a fixed pilot subset while varying `--k_frames`.

How these were produced (conceptually):

```bash
python scripts/compute_similarity_and_labels.py \
  --quality_csv data/metadata/quality_metrics_pilot.csv \
  --annotations_json data/raw/hussain/video/cleaned_result/video_Effective_clean.json \
  --generation_log_csv data/metadata/svd_log_gpu0.csv \
  --out_csv data/tmp/sim_k8.csv \
  --k_frames 8 \
  --subset_n 200 \
  --subset_seed 42
```

Notes:
- The command above requires access to the underlying pilot videos referenced by the generation log (videos are not distributed).
- These CSVs are included here so the *sensitivity evidence* is available for inspection even without videos.

### `seed_mean_tables/`

Supporting artifacts for the robustness reporting (mean±std across seeds):

- `table_main_results_per_seed.csv`: per-seed main results
- `table_main_results_mean_std.csv`: mean±std summary used to cross-check robustness statements
- `table_quality_correlations.csv`: correlation table variant produced during the multi-seed run
- `table_main_results.tex`: LaTeX table output from the multi-seed artifact generation run

### `extra_scripts/` (optional / legacy helpers)

These scripts are **not required** for the primary reproduction path (`python scripts/run_full_pipeline.py --run_artifacts`) but are included for transparency and for users who want to explore alternative/older analysis flows:

- `build_lambda_datasets.py`: helper to regenerate lambda-sweep datasets (if you choose not to ship prebuilt `data/metadata/lambda_sensitivity/`).
- `compare_baselines.py`, `reproduce_baselines.py`, `compute_correlations.py`: auxiliary analysis scripts from development.
